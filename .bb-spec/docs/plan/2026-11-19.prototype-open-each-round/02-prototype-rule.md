# /prototype 规程改成每轮展示一次

## 目标
`/prototype` 规程让主对话在每一轮交还给用户之前，按"原型文件这一轮改过没有 + 报告的「需要用户看页面」"决定是否运行 `show-prototype.sh` 展示原型；不再提醒用户刷新。

## 业务规则（来源：PRD open-each-round 约束 1、2、5～10）
- "一轮"＝用户发一条消息到主对话把结果交还给用户为止；一轮里派几次活、发几次消息都只在交还前判断一次，最多展示一次。
- 原型文件这一轮没改过 → 不展示；是否改过只看主对话在这一轮开始前和交还前各运行一次 `stat -f %m` 的结果，不看报告措辞。
- 最后一份报告「需要用户看页面」是"否" → 不展示；出原型模式下缺这一行 → 按"是"处理。
- 交回确认内容清单的那一轮、对比模式转问题和答复时 → 不展示。
- 主对话不提醒用户手动刷新：规程里不能再出现"提醒用户刷新""已经对这个原型文件执行过 `open`""换了新的原型子代理也不重新计数"。
- 反历史包袱：新文字只写现在怎么做，不写"不再提醒刷新"这类否定句；对比一节原来的"不打开原型，也不提醒刷新"改成"不展示原型"。

## 成品定义

`SKILL.md`「出原型」第 5 步中，把从 `   - 按报告最后一行「需要用户看页面」决定要不要打开原型：` 开始、到 `     - 打开过没有，只看主对话自己在本次对话里执行过的 `open`，不看报告里写了什么；换了新的原型子代理也不重新计数` 为止的 7 行整段删除；第 5 步其余三条（原样给用户看、展示页、SendMessage）原样保留、顺序不变，并在第 5 步最后一条之后追加下面这段（缩进与第 5 步子项一致）：

```markdown
   - 每一轮交还给用户之前，按下面决定要不要展示原型。"一轮"指从用户发一条消息，到主对话把结果交还给用户为止；这期间派了几次活、给子代理发了几次消息，都只在最后交还之前判断一次，一轮最多展示一次：
     - 这一轮开始时（派活或发消息之前）运行 `stat -f %m <原型文件路径>` 记下修改时间，文件还不存在就记作"不存在"；交还之前再运行一次。两次结果相同，说明这一轮原型文件没改过：不展示。改过没有只看这两次结果，不看报告里写了什么
     - 子代理交回确认内容清单的那一轮：不展示
     - 这一轮最后一份报告的最后一行「需要用户看页面」是"否"：不展示
     - 出原型模式下最后一份报告里没有这一行：按"是"处理
     - 原型文件改过、且「需要用户看页面」是"是"：运行 `${CLAUDE_PLUGIN_ROOT}/scripts/show-prototype.sh <原型文件路径>` 展示原型。脚本在 Chrome、Safari 里找到这个文件已经开着的标签页就切过去并刷新，找不到或出错时新开一个标签页
```
