# 做计划和执行时的新技术批准

## 目标
`/plan` 把计划用到的全部新技术逐项列出、一次弹窗批准，批准后写进七栏「新增技术」表；`/exec` 和实现子代理只认这张表，碰到表外的新技术先停下问用户。

## 业务规则（来源：PRD 01-plan-tech-list、02-unlisted-tech-stop）
- 新技术指项目里原来没有的外部东西：第三方库、框架、编程语言、运行时、数据库、中间件、构建或测试工具、容器镜像、CI Action、外部服务接口。插件默认栈、用户点名的也要列。
- `/plan` 在正文逐项列出，每项七项内容：名称、类别、来源（插件默认栈 / 用户点名 / Claude 提议）、用途、现有手段为什么不够、替代方案为什么不选、版本策略。
- 只弹一次窗，问"上面 N 项新技术，你同意引入吗？"，选项依次是"全部同意，继续"、"否决其中几项"。否决几项只替换这几项，整份清单再列一遍再弹窗。用户选"全部同意，继续"之前不写 plan 文档。
- 批准后写进 plan 的「新增技术」表，七栏依次是：名称、类别、来源、用途、现有手段为什么不够、替代方案为什么不选、版本策略。没有新技术时不弹窗、没有这张表。
- `/exec` 发现某一步引入了表外的新技术，这一步不算完成，先停下按同样格式问用户；同意后先补进表再继续。用户同意前，不改依赖文件和配置文件。
- `/prd` 最后确认弹窗里"已阅读，通过并执行"的说明，要写清中途会在需要引入新技术时停下。
