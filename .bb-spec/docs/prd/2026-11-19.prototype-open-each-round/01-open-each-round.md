# 每一轮改完切到原型页并刷新

## 用户故事

### P0：作为出原型的用户，我想要每次提完修改意见后，浏览器自动切到原型页并显示最新版本，以便不用自己找页面、刷新，也不会堆出一排相同的标签页

**用例（主路径）**
- 场景：小王用 Chrome，在运行 `/prototype 订单列表加导出按钮`。
- 操作：
  1. 第 1 轮：子代理还没画页面，只问"要不要把项目跑起来看"，报告最后一行写"需要用户看页面：否"。
  2. 第 2 轮：小王答"不用跑"。子代理画完订单列表页，报告写"是"。
  3. 第 3 轮：小王说"导出按钮挪到右边"。子代理改完，报告写"是"。
  4. 第 4 轮：小王问"为什么表头是灰色的"。子代理只回答问题，没改原型文件，报告写"是"。
  5. 第 5 轮：小王说"表头换成白色"。子代理改完，报告写"是"；主对话发现报告里说漏改了一处，又给子代理发了一次消息，子代理再改一次，报告写"是"。
- 预期：第 1、4 轮浏览器没有动静；第 2 轮 Chrome 新开 1 个原型标签页；第 3、5 轮 Chrome 切到这个标签页并刷新，显示这一轮改完后的样子，原型标签页始终只有 1 个。第 5 轮里子代理改了两次，也只切换刷新 1 次。整个过程主对话不提醒小王手动刷新。

**用例（边界：用户关掉了原型标签页）**
- 场景：第 2 轮打开原型后，小王把原型标签页关了。
- 操作：第 3 轮子代理改完，报告写"是"。
- 预期：Chrome 新开 1 个原型标签页，显示最新版本。

**用例（边界：不能控制浏览器）**
- 场景：小王用 Firefox；或者用 Chrome，但 macOS 弹窗问"是否允许终端控制 Chrome"时选了不允许。
- 操作：子代理改完原型，报告写"是"。
- 预期：新开 1 个原型标签页，显示最新版本；主对话照常把结果交给小王，不报错中断。

**用例（边界：报告漏了这一行）**
- 场景：出原型模式下，子代理这一轮改了原型文件，报告里没有「需要用户看页面」这一行。
- 操作：主对话收到报告，准备交还给用户。
- 预期：按"是"处理，展示一次原型。

## 约束

1. "一轮"指从用户发一条消息，到主对话把结果交还给用户为止。
2. 一轮里原型文件被改过、且这一轮最后一份报告的「需要用户看页面」是"是" → 主对话在所有修改做完、交还给用户之前，展示一次原型。
3. 展示原型：Chrome 或 Safari 里已经开着这个原型文件的标签页 → 把这个浏览器切到前台、切到这个标签页并刷新，这个文件的标签页数量不变；开着多个时只切换刷新其中 1 个。
4. 展示原型：Chrome 和 Safari 里都没有开着这个原型文件，或者查找、切换、刷新中任何一步出错 → 执行 `open <原型文件路径>` 新开 1 个标签页。
5. 一轮里最多展示一次：这一轮主对话多次派活或多次给子代理发消息，只在最后交还给用户之前判断一次。
6. 原型文件这一轮没被改过 → 不展示。是否改过，以主对话亲自核对的文件修改时间为准（这一轮开始前和交还前各看一次），不看报告里写了什么。
7. 最后一份报告写"否" → 不展示。
8. 出原型模式下最后一份报告缺「需要用户看页面」这一行 → 按"是"处理。
9. 子代理交回确认内容清单的那一轮、对比（`--compare`）模式转问题和答复时 → 不展示。
10. 主对话不提醒用户手动刷新页面。

## 验收

- [ ] `/prototype` 规程写明"一轮"是从用户发一条消息到主对话交还结果为止。（约束 1）
- [ ] `/prototype` 规程写明：这一轮原型文件改过、最后一份报告写"是"时，在交还给用户之前展示一次原型。（约束 2）
- [ ] Chrome 里已经开着原型文件时展示一次原型 → Chrome 切到这个标签页，内容变成最新版本，这个文件的标签页数量不变。（约束 3）
- [ ] Chrome 里开着同一个原型文件的 2 个标签页时展示一次原型 → 其中 1 个被切到并刷新，标签页数量仍是 2。（约束 3）
- [ ] Chrome 和 Safari 里都没开着原型文件时展示一次原型 → 新开 1 个标签页，内容是最新版本。（约束 4）
- [ ] 查找或切换出错时（例如脚本被拒绝控制浏览器）展示一次原型 → 退回执行 `open`，新开 1 个标签页，不中断流程。（约束 4）
- [ ] `/prototype` 规程写明：一轮里最多展示一次，多次派活或发消息只在交还前判断一次。（约束 5）
- [ ] `/prototype` 规程写明：原型文件这一轮没改过就不展示，靠主对话在这一轮开始前和交还前各看一次文件修改时间来判断，不看报告措辞。（约束 6）
- [ ] `/prototype` 规程写明：报告写"否"时不展示。（约束 7）
- [ ] `/prototype` 规程写明：出原型模式下报告缺这一行时按"是"处理。（约束 8）
- [ ] `/prototype` 规程写明：交回确认内容清单的那一轮和对比模式不展示。（约束 9）
- [ ] `/prototype` 规程里搜不到"提醒用户刷新"、"已经对这个原型文件执行过 `open`"、"换了新的原型子代理也不重新计数"。（约束 10）

## 验证路径

1. 读 `plugins/bb-spec-workflow/skills/prototype/SKILL.md`「出原型」第 5 步 → 展示原型的时机和条件按约束 1、2、5～9 写。
2. 在 Chrome 里开着一个测试 HTML 文件，改它的内容后跑一次展示原型的那一步 → Chrome 切到这个标签页并显示新内容，这个文件的标签页仍是 1 个。
3. 关掉这个标签页再跑一次 → 新开 1 个标签页。
4. 在规程里搜"刷新" → 没有"提醒用户刷新"的写法。
