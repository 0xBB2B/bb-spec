# 原型外壳

外壳是所有原型共用的 HTML 外框，每次只往里填内容。下文的"框"指外壳中间显示正式页面的区域，框里的内容才是要做进产品的。

## 用户故事

### P0：作为确认原型的用户，我想要一眼分清正式页面和设计说明，以便放心确认界面

**用例（主路径）**
- 场景：用户收到一份订单页面的原型，要决定能不能照着做。
- 操作：在浏览器打开原型，依次点左栏的「空数据」「加载中」「出错」。
- 预期：框里每次只显示订单页面本身；说明只出现在框外的左栏和底部，并标着「设计说明 · 不属于页面」。

**用例（边界：框里的页面自己会跳转）**
- 场景：原型里点一笔订单会进入订单详情。
- 操作：在框里点这笔订单。
- 预期：框里显示订单详情，左栏选中项、框上方提示和底部说明都换成订单详情的内容。

### P0：作为对比方案的用户，我想要清楚知道当前看的是哪个方案，以便做出选择

**用例（主路径）**
- 场景：原型有方案 A 表格、方案 B 卡片两个方案。
- 操作：停在「订单列表 · 正常」，在左栏最上方点方案 B。
- 预期：框里换成卡片样式，页面和状态不变，框上方显示「当前看的是 方案 B：卡片」。

**用例（边界：只有一个方案）**
- 场景：这份原型只有一个方案。
- 操作：打开原型。
- 预期：左栏没有方案切换框，框上方没有方案标签。

### P0：作为确认终端界面的用户，我想要看到真实终端的样子，以便判断实际效果

**用例（主路径）**
- 场景：需求改的是命令行输出。
- 操作：在左栏选终端页面，依次点第 1、2、3 步。
- 预期：框里是全屏终端的样子，内容从左上角开始，底色铺满框。

## 约束

**三块布局**
- C1：打开任意原型 → 屏幕分成左栏、框、底部说明三块，左栏在左，框在右上，底部说明在框的下方。
- C2：框里的内容与外壳完全隔开 → 框里的样式影响不到外壳，外壳的样式也影响不到框里；框里读不到「设计说明」「被设计的页面」「只在原型里成立」「当前看的是」这些外壳文字。
- C3：外壳用深色底，左栏与右边之间有琥珀色竖线，选中项是琥珀色底；框的周围是浅灰色 → 外壳的颜色不随框里的内容变化。

**左栏**
- C4：左栏顶部依次显示标签「设计说明 · 不属于页面」、原型标题、「第 N 版 · 这一栏上线后不存在」。
- C5：左栏有「切换要看的内容」，下面分「页面」和「状态」两组按钮；页面是多步交互时，第二组的名字写「步骤」。

**框上方提示**
- C6：框上方一行，左边显示「▼ 被设计的页面：只有这个框里的内容要实现」，右边显示「<页面名> · <状态名>」。

**底部说明**
- C7：底部显示标签「设计说明 · 不属于页面」和「这一块上线后不存在」，下面三列的标题依次是「这个画面的说明」「只在原型里成立」「还没确认的问题」。
- C8：底部固定占窗口高度的 26%；切换页面、状态、方案时，框的高度不变；说明太长时只在底部内部滚动。
- C9：「只在原型里成立」或「还没确认的问题」没有内容时，这一列显示「无」。

**切换**
- C10：点左栏的按钮 → 框、框上方提示、底部说明都换成对应内容，被点的按钮变成选中样式。
- C11：框里的页面自己跳到另一个页面或状态时 → 左栏选中项、框上方提示、底部说明同步更新。

**多方案**
- C12：原型有 2 个及以上方案时 → 左栏最上方显示单独描边的切换框，标题为「有 N 个方案，点这里切换对比」；框上方提示语后面显示标签「当前看的是 <方案名>」。
- C13：切换方案时 → 当前页面和状态保持不变。
- C14：框里的页面跳转时 → 当前方案保持不变。
- C15：原型只有 1 个方案时 → 切换框和方案标签都不显示，也不占位置。
- C16：原型有多个方案时 → 「这个画面的说明」第一条写当前方案的取舍；方案之间没有差别的画面，第一条写「各方案在这个画面上一样。」
- C17：原型有多个方案时 → 「还没确认的问题」第一条自动显示要选哪个方案：2 个方案写「选方案 A 还是方案 B」，3 个及以上写「选方案 A、方案 B 还是方案 C」。

**终端界面**
- C18：框里是终端界面时 → 内容从左上角开始，底色铺满整个框，用等宽字体，按 80 列换行；内容没超出框时不出现滚动条。

**文件形式**
- C19：一份原型是一个 HTML 文件 → 双击就能在浏览器打开，不需要联网，也不需要构建。
- C20：浏览器窗口窄于 960 像素时 → 页面出现横向滚动，三块布局不变。

## 验收

- [ ] C1：打开外壳做的原型，能看到左栏、框、底部说明三块，位置符合约定。
- [ ] C2：切换所有页面、状态、方案，框里的文字都不含四段外壳文字；框里写的样式不改变外壳，外壳样式不改变框里。
- [ ] C3：框里分别显示白底页面和黑底终端时，外壳颜色不变。
- [ ] C4：左栏顶部三项内容和文字符合约定。
- [ ] C5：普通页面第二组叫「状态」，多步交互页面第二组叫「步骤」。
- [ ] C6：框上方左右两段文字符合约定。
- [ ] C7：底部标签、提示和三列标题符合约定。
- [ ] C8：窗口高 720 时，所有组合下底部高度相同、框高度相同；塞入 20 条说明后框高度不变，底部能滚动。
- [ ] C9：两列留空时都显示「无」。
- [ ] C10：点每个按钮，三处内容都更新，选中样式正确。
- [ ] C11：点框里的跳转入口，三处内容都同步。
- [ ] C12：2 个方案时能看到切换框和方案标签，文字符合约定。
- [ ] C13：在任一页面和状态下切方案，页面和状态不变。
- [ ] C14：在方案 B 下点框里的跳转入口，仍停留在方案 B。
- [ ] C15：只留 1 个方案时，切换框和方案标签都不显示。
- [ ] C16：有差别的画面第一条是方案取舍，没差别的画面第一条是「各方案在这个画面上一样。」
- [ ] C17：2 个方案、3 个方案时第一条问题分别符合约定写法。
- [ ] C18：终端内容的左上角紧贴框的左上角（留 8 像素边距），底色铺满框，80 列换行，没有多余滚动条。
- [ ] C19：断网时用 `file://` 打开原型，切换功能都正常，文件不引用任何外部资源。
- [ ] C20：窗口宽 800 像素时出现横向滚动，三块布局不变。

## 验证路径

1. 用外壳填一份有 2 个方案、3 个页面（含 1 个终端页面）的原型，双击打开 → 看到三块布局。
2. 依次点方案、页面、状态的每个按钮 → 三处内容同步更新，框里没有外壳文字，框高度不变。
3. 在框里点跳转入口 → 左栏跟着变，当前方案不变。
4. 删到只剩 1 个方案后重新打开 → 方案切换框和标签都不显示。
