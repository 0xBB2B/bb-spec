# 蓝图外壳

外壳是所有原型共用的 HTML 外框。下文的"框"指外壳中间显示正式页面的区域，框里的内容才要做进产品。

## 用户故事

### P0：作为确认原型的用户，我想要所有原型都是同一种样子，以便不用每次重新适应

**用例（主路径）**
- 场景：用户先后确认两个需求的原型，两个项目都没有自己的设计。
- 操作：分别打开两份原型。
- 预期：外壳都是蓝图样式；框里的按钮、表格、卡片样式相同；终端配色相同。

### P0：作为确认原型的用户，我想要框里还原项目真实的样子，以便确认的就是实际效果

**用例（主路径）**
- 场景：项目有自己的紫色设计。
- 操作：打开这个项目的原型。
- 预期：框里是紫色页面，外壳仍是蓝图样式；框里看不到默认页面样式的痕迹。

**用例（边界：项目样式写得很霸道）**
- 场景：项目样式里写了对所有元素强制生效的字体和颜色规则。
- 操作：打开原型，切换页面和状态。
- 预期：外壳的颜色和字体都不变。

### P0：作为看原型的用户，我想要底部没有多余空行，以便框尽量大

**用例（主路径）**
- 场景：用户在 2000×1000 的窗口里看原型，说明最多 3 行。
- 操作：打开原型，切换各个状态。
- 预期：说明最长的画面下方只留 8 像素，框的高度全程不变。

**用例（边界：说明特别长）**
- 场景：某个状态写了 20 条说明。
- 操作：切到这个状态。
- 预期：底部最高占窗口高度的 30%，说明在底部内部滚动，框的高度不变。

## 约束

**蓝图样式**
- C1：打开任意原型 → 外壳是藏蓝底（`#12264a`）加细网格，文字用等宽字体，所有边角都是方角。
- C2：外壳的分界都用青色（`#7fd4ff`）虚线：左栏和右边之间、框的外面、底部说明的上面、方案切换框。
- C3：「设计说明 · 不属于页面」标签是青色虚线框、青色字，没有填充色。
- C4：切换按钮未选中时是细线框、透明底；选中时是浅青色实心底、深色字。
- C5：框上方一行，左边显示「▼ 被设计的页面：只有这个框里的内容要实现」；右边依次显示方案标签和「<页面名> · <状态名>」。
- C6：方案标签只写方案名，比如「方案 A：表格」；只有 1 个方案时不显示。
- C7：有 2 个及以上方案时，切换框的标题是「这份原型有 N 个方案，点这里切换对比」。
- C8：「只在原型里成立」「还没确认的问题」没内容时显示不带序号的「无」。

**页面样式**
- C9：填写区的 `css` 留空或不写时 → 框里用默认页面样式：浅灰底、白色标题栏和卡片、蓝色按钮，并提供表格、提示条、占位条的样式。
- C10：填写区的 `css` 写了项目样式时 → 框里只有项目样式，默认页面样式完全不生效。
- C11：框里的任何样式都不改变外壳；外壳的样式也不进入框里，包括强制生效的全局规则。

**终端**
- C12：框里是终端界面时 → 底色是 `#0b1730`，文字是 `#d7e6ff`，绿、黄、蓝、红分别是 `#7ee7c1`、`#ffd479`、`#7fd4ff`、`#ff8f8f`，所有终端原型都一样。

**底部高度**
- C13：底部高度等于这份原型所有画面里最长的说明的高度 → 说明最长的画面下方只留 8 像素。
- C14：切换方案、页面、状态时 → 底部和框的高度都不变。
- C15：最长的说明超过窗口高度的 30% 时 → 底部高 30%，说明在底部内部滚动。
- C16：窗口大小改变时 → 底部高度重新计算，当前画面的说明不变。

## 验收

- [ ] C1：外壳底色是 `#12264a`，有细网格，文字是等宽字体，外壳里没有圆角。
- [ ] C2：四处分界都是 `#7fd4ff` 虚线。
- [ ] C3：标签是青色虚线框、青色字、无填充。
- [ ] C4：按钮未选中和选中时的样式符合约定。
- [ ] C5：框上方两端的内容和顺序符合约定。
- [ ] C6：2 个方案时方案标签文字是「方案 A：表格」；1 个方案时不显示。
- [ ] C7：切换框标题文字符合约定。
- [ ] C8：两列没内容时显示「无」，没有序号。
- [ ] C9：`css` 留空和不写时，框里都有默认页面样式：底色 `#f5f7fa`，卡片白色，按钮 `#2563eb`。
- [ ] C10：写了 `css` 时，框里不含默认页面样式。
- [ ] C11：框里写对所有元素强制生效的规则后，外壳的颜色和字体不变；框里读不到外壳的颜色变量。
- [ ] C12：终端的底色和五种文字颜色符合约定。
- [ ] C13：窗口 1280×720、2000×1000 时，说明最长的画面下方都留 8 像素。
- [ ] C14：所有组合下框和底部的高度都不变。
- [ ] C15：塞入 20 条说明时，底部高度等于窗口高度的 30%，底部能滚动，框高度不变。
- [ ] C16：把窗口从 2000 宽改到 960 宽后，底部高度重新计算，当前说明不变。

## 验证路径

1. 用外壳填一份有 2 个方案、4 个页面（含 1 个终端页面）的原型，双击打开 → 看到蓝图样式。
2. 依次切换所有方案、页面、状态 → 框和底部的高度都不变。
3. 给 `css` 填上强制生效的项目样式后重新打开 → 框里是项目样式，外壳不变。
4. 删到只剩 1 个方案 → 方案切换框和方案标签都不显示。
