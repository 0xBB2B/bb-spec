# 术语表

> 全项目术语唯一权威源，仅 /prd 维护。跨语言 / 跨文档以英文锚点对齐；别名只登记实际用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| ui-preview | 改界面前给用户确认用的单文件 HTML 页面，存放在缓存目录、不进 git | 简体「原型」「界面预览」「预览页」 |
| preview-shell | 所有原型共用的 HTML 外框，由左栏、框上方提示、底部说明组成，这些内容都不做进产品 | 简体「外壳」「原型外壳」 |
| preview-frame | 外壳中间显示正式页面的区域，只有这里的内容要做进产品 | 简体「框」 |
