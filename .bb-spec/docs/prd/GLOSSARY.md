# 术语表

> 全项目术语唯一权威源，仅 /prd 维护。跨语言 / 跨文档以英文锚点对齐；别名只登记实际用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| ui-preview | 改界面前给用户确认用的单文件 HTML 页面，存放在缓存目录、不进 git | 简体「原型」「界面预览」「预览页」 |
| preview-shell | 所有原型共用的 HTML 外框，由左栏、框上方提示、底部说明组成，这些内容都不做进产品 | 简体「外壳」「原型外壳」 |
| preview-frame | 外壳中间显示正式页面的区域，只有这里的内容要做进产品 | 简体「框」 |
| shell-theme | 外壳的配色，分明亮和暗黑两套，打开原型时跟系统外观一致；框里的页面不随它变化 | 简体「主题」「明亮主题」「暗黑主题」 |
| preview-scheme | 同一份原型里并列给用户对比的几种设计之一，有短名（如「方案 A」）和一句特点 | 简体「方案」 |
| default-page-style | 项目没有自己的设计时，框里使用的统一页面样式；填写了项目样式后完全不生效 | 简体「默认页面样式」 |
| turn | Claude 从开始工作到把控制权交还给用户的一段连续过程 | 简体「回合」 |
| background-script | Claude 用后台方式启动、运行一段时间后会自己结束的命令，如测试、构建、审查 | 简体「后台脚本」 |
| long-running-service | Claude 用后台方式启动、不会自己结束的命令，如 dev server、watch、`tail -f` | 简体「常驻服务」 |
| new-tech | 项目里原来没有的外部东西：第三方库、框架、编程语言、运行时、数据库、中间件、构建或测试工具、容器镜像、CI Action、外部服务接口；语言标准库、依赖文件里直接声明的、升级已在用依赖的版本都不算；不在标准库里的官方扩展库、代码里直接引用的间接依赖算 | 简体「新技术」 |
| new-tech-list | 引入新技术前给用户批准的清单，每项写名称、类别、来源、用途、现有手段为什么不够、替代方案为什么不选、版本策略 | 简体「新技术清单」「新增技术」 |
| plugin-default-stack | bb-spec 插件规则里预先定好的技术选择，如新前端项目用 Vue 3 + Vite + Tailwind + bun、Go 日志用 `log/slog` | 简体「插件默认栈」「默认技术栈」 |
