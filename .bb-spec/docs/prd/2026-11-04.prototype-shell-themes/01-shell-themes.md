# 明暗主题

外壳是所有原型共用的 HTML 外框，由左栏、框上方提示、底部说明组成。"框"是外壳中间显示正式页面的区域，只有框里的内容要做进产品。"主题"指外壳的配色，分明亮和暗黑两套。

## 用户故事

### P0：作为看原型的用户，我想要外壳的深浅跟我的系统一致，以便看原型时眼睛不累

**用例（主路径：浅色系统）**
- 场景：用户的电脑设成浅色外观。
- 操作：双击打开一份原型。
- 预期：外壳是雾灰蓝底、深蓝虚线、深色字；框上方最右端的「☀ 明亮」是选中样式。

**用例（主路径：深色系统）**
- 场景：用户的电脑设成深色外观。
- 操作：双击打开同一份原型。
- 预期：外壳是石墨深灰底、灰蓝虚线、浅色字；「☾ 暗黑」是选中样式。

### P0：作为看原型的用户，我想要手动切换明暗，以便在当前环境下挑看着舒服的那套

**用例（主路径）**
- 场景：系统是浅色，用户正在看方案 B 的「订单列表 · 出错」。
- 操作：点框上方最右端的「☾ 暗黑」。
- 预期：外壳立即变成暗黑主题；框里还是方案 B 的「订单列表 · 出错」，页面样子不变；左栏选中项不变；框和底部的高度不变。

**用例（边界：手动切换后系统变了）**
- 场景：系统是浅色，用户手动切到了暗黑。
- 操作：原型开着，把系统改成深色，再改回浅色。
- 预期：外壳一直是暗黑主题。

**用例（边界：没手动切换时系统变了）**
- 场景：系统是浅色，用户打开原型后没点过主题按钮。
- 操作：原型开着，把系统改成深色。
- 预期：外壳立即变成暗黑主题。

**用例（边界：重新打开）**
- 场景：系统是浅色，用户手动切到暗黑后关掉了原型。
- 操作：再次打开这份原型。
- 预期：外壳是明亮主题。

### P1：作为看终端原型的用户，我想要终端页面在两种主题下一样，以便看到的就是真实终端的样子

**用例（主路径）**
- 场景：原型里有一个终端页面。
- 操作：在明亮、暗黑两种主题下分别切到这个页面。
- 预期：两次框里的终端底色和文字颜色完全相同。

## 约束

**配色**
- C1：明亮主题 → 外壳底色 `#d5dae1`，细分隔线 `#b7bfca`，正文字 `#1d2633`，次要文字 `#4f5b6b`，虚线和强调色 `#47607f`，网格线 `rgba(71,96,127,.06)`，选中按钮的填充 `#c2cad5`、字 `#1d2633`。
- C2：暗黑主题 → 外壳底色 `#26282c`，细分隔线 `#3a3d43`，正文字 `#d4d4d4`，次要文字 `#8f949b`，虚线和强调色 `#8e9aa8`，网格线 `rgba(255,255,255,.03)`，选中按钮的填充 `#33363c`、字 `#e6e6e6`。
- C3：两种主题下 → 外壳都有细网格、等宽字体、方角；左栏和右边之间、框的外面、底部说明的上面都是强调色虚线；「设计说明 · 不属于页面」标签是强调色虚线框、强调色字、没有填充色。
- C4：外壳里的切换按钮 → 未选中时是细分隔线颜色的细线框、透明底；选中时是强调色细线框、选中按钮的填充色、选中按钮的字色，字加粗。
- C5：框里的页面 → 两种主题下完全一样：默认页面样式、项目样式、终端配色都不随主题变化。

**主题切换**
- C6：框上方一行的最右端显示「☀ 明亮」「☾ 暗黑」两个按钮，和它左边的内容之间用一条细分隔线颜色的竖线隔开；只有 1 个方案时也显示。
- C7：打开原型时 → 系统是浅色外观就用明亮主题，是深色外观就用暗黑主题，对应按钮是选中样式。
- C8：点「☀ 明亮」或「☾ 暗黑」→ 外壳立即换成对应主题，按钮选中样式跟着变；当前方案、页面、状态和框里内容不变；框和底部的高度不变。
- C9：用户还没点过主题按钮时系统外观变了 → 外壳立即跟着换主题；点过之后系统外观再变 → 外壳不变。
- C10：关闭原型再打开 → 按 C7 跟系统一致，不沿用上次手动选的主题。

## 验收

- [ ] C1：明亮主题下外壳底色、分隔线、两种文字、强调色、网格、选中按钮的颜色都和约定一致。
- [ ] C2：暗黑主题下同上各项颜色都和约定一致。
- [ ] C3：两种主题下都有网格、等宽字体，外壳里没有圆角；三处分界都是强调色虚线；标签是强调色虚线框、强调色字、无填充。
- [ ] C4：两种主题下切换按钮未选中、选中的样式符合约定。
- [ ] C5：同一个网页画面和同一个终端画面，在两种主题下框里的内容和样式完全相同。
- [ ] C6：2 个方案和 1 个方案时，框上方最右端都有「☀ 明亮」「☾ 暗黑」，左边有一条竖线。
- [ ] C7：模拟浅色外观打开是明亮主题，模拟深色外观打开是暗黑主题。
- [ ] C8：切到方案 B 某个状态后点主题按钮，主题变了，方案、页面、状态、框里内容、框和底部的高度都不变。
- [ ] C9：没点过主题按钮时把外观从浅色改成深色，外壳变成暗黑；点过「☀ 明亮」后再改外观，外壳保持明亮。
- [ ] C10：手动切到暗黑后重新打开（外观为浅色），外壳是明亮主题。

## 验证路径

1. 系统设成浅色，打开一份含 2 个方案、1 个终端页面的原型 → 外壳是雾灰蓝，「☀ 明亮」被选中。
2. 切到方案 B 的某个状态，点「☾ 暗黑」→ 外壳变成石墨深灰，框里内容和框、底部的高度都不变。
3. 切到终端页面，在两种主题之间来回切 → 框里的终端一模一样。
4. 把系统改成深色再改回浅色 → 外壳一直是暗黑。
5. 关掉重新打开 → 外壳是明亮主题；不点按钮，把系统改成深色 → 外壳变成暗黑。
