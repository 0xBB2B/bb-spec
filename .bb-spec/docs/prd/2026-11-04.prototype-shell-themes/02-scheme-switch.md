# 方案切换挪到右上角

外壳是所有原型共用的 HTML 外框，由左栏、框上方提示、底部说明组成。"框"是外壳中间显示正式页面的区域。"方案"是同一份原型里并列给用户对比的几种设计，每个方案有一个短名（如「方案 A」）和一句特点（如「表格」）。

## 用户故事

### P0：作为对比方案的用户，我想要方案切换和页面、状态切换分开，以便一眼知道自己在切什么

**用例（主路径）**
- 场景：一份原型有方案 A（表格）、方案 B（卡片）两个方案，有订单列表、订单详情两个页面。
- 操作：打开原型，看左栏和框上方；再点右上角的「方案 B：卡片」。
- 预期：框上方右侧有「方案」两个字和「方案 A：表格」「方案 B：卡片」两个按钮，方案 A 被选中；左栏只有页面和状态两组切换，最上面写着「当前：方案 A：表格」。点方案 B 后，框里换成方案 B 的同一个页面和状态，左栏写着「当前：方案 B：卡片」，选中的页面和状态不变。

**用例（边界：只有 1 个方案）**
- 场景：一份原型只有一个方案。
- 操作：打开原型。
- 预期：框上方右侧没有方案按钮，只有明暗主题切换；左栏没有「当前：…」这一行。

**用例（边界：方案很多）**
- 场景：一份原型有 7 个方案，窗口宽 1280 像素。
- 操作：打开原型。
- 预期：方案按钮一行放不下时排到第二行，框上方左边的提示文字完整显示、不被截断。

## 约束

- C1：有 2 个及以上方案时 → 框上方一行的右侧显示「方案」两个字，后面每个方案一个按钮，按钮文字是「<短名>：<特点>」，如「方案 A：表格」；当前方案是选中样式；这组按钮排在明暗主题切换的左边。
- C2：点一个方案按钮 → 框里换成这个方案的同一个页面和状态，左栏选中的页面和状态不变。
- C3：左栏从上到下是「设计说明 · 不属于页面」标签、原型标题和版本、页面和状态两组切换；有 2 个及以上方案时，切换区最上面显示「当前：<短名>：<特点>」，切换方案后跟着变。
- C4：只有 1 个方案时 → 框上方右侧没有方案按钮和「方案」两个字，左栏没有「当前：…」这一行。
- C5：框上方一行的左边依次显示「▼ 被设计的页面：只有这个框里的内容要实现」和「<页面名> · <状态名>」，始终完整显示；右侧的按钮一行放不下时换到下一行，整组靠右对齐。
- C6：切换方案、页面、状态时 → 底部说明的高度不变；方案按钮的行数不变时框的高度也不变。

## 验收

- [ ] C1：2 个方案时框上方右侧有「方案」和两个按钮，文字是「方案 A：表格」「方案 B：卡片」，当前方案是选中样式，按钮在主题切换左边。
- [ ] C2：在方案 A 的「订单列表 · 出错」点方案 B 后，框里是方案 B 的「订单列表 · 出错」，左栏选中项不变。
- [ ] C3：左栏的内容和顺序符合约定，2 个方案时最上面是「当前：方案 A：表格」，点方案 B 后变成「当前：方案 B：卡片」。
- [ ] C4：1 个方案时框上方右侧没有方案按钮和「方案」，左栏没有「当前：…」。
- [ ] C5：7 个方案、窗口宽 1280 像素时，左边提示文字和「<页面名> · <状态名>」完整显示，方案按钮换行且靠右。
- [ ] C6：切换所有方案、页面、状态组合时，底部高度不变，框高度不变。

## 验证路径

1. 打开一份有 2 个方案的原型 → 方案按钮在框上方右侧，左栏顶部写着当前方案。
2. 在某个页面的某个状态下点另一个方案 → 框里换成另一个方案的同一个页面和状态，左栏选中项不变、当前方案名跟着变。
3. 删到只剩 1 个方案后重新打开 → 方案按钮和「当前：…」都不显示。
4. 填 7 个方案、窗口 1280 宽打开 → 方案按钮换行，左边提示文字完整。
