# 原型规程跟着调整

`/prototype` 是出界面原型、做完后拿真实界面和原型对比的规程（`plugins/bb-spec-workflow/skills/prototype/SKILL.md`）。原型外壳去掉底部说明区后，规程里原来要求"写进 `note`、`fake`、`openQuestions`"的内容需要换个地方说；外壳能切页面主题后，规程要写清楚什么时候声明几套主题。DESIGN.md 是项目根目录的设计规范，「颜色」一节写项目的颜色，支持深色模式时写明暗两套。"对比"指功能做完后，`/prototype --compare` 拿真实界面和原型框里的内容逐项对照。

## 用户故事

### P0：作为看原型的用户，我想要原型的说明在对话里讲清楚，以便不看外壳也知道这版原型的依据和假的部分

**用例（主路径）**
- 场景：Claude 按 DESIGN.md「颜色」「组件」两节和 `src/layouts/Main.vue` 画了订单列表原型，订单是编的，「导出」按钮点了没反应，还有一个问题没确认：导出用 CSV 还是 Excel。
- 操作：Claude 打开原型给用户看。
- 预期：Claude 在同一条回复里告诉用户：照着 DESIGN.md 的哪几节、读了哪些源码文件；哪些是假数据和假操作；还没确认的问题，并请用户回答。

**用例（边界：多方案）**
- 场景：原型里有方案 A、B 两个方案。
- 操作：Claude 打开原型给用户看。
- 预期：Claude 在对话里讲每个方案的取舍，并问用户选哪个方案。

### P0：作为看原型的用户，我想要原型的主题套数和 DESIGN.md 一致，以便每套配色都能确认

**用例（主路径）**
- 场景：项目 DESIGN.md 的「颜色」一节写了明亮、暗黑两套颜色。
- 操作：Claude 出一份原型。
- 预期：原型声明两套主题，项目样式里两套颜色都写了，右上角可以切换。

**用例（边界：只有一套）**
- 场景：DESIGN.md「颜色」一节只写了一套颜色，用户也没提主题。
- 操作：Claude 出一份原型。
- 预期：原型不声明主题，右上角没有主题切换。

### P1：作为做完功能的用户，我想要对比时不把示例数据当成差异，以便对比结果只报真问题

**用例（主路径）**
- 场景：原型里订单号是 A1024、客户是王小明；真实界面里订单号是 B2001、客户是赵敏，布局、文案、状态、交互都和原型一样。
- 操作：运行 `/prototype --compare <原型文件>`。
- 预期：结果是「一致」。

## 约束

- C1：规程里没有 `note`、`fake`、`openQuestions` 三个填写项。Claude 打开原型给用户看时，在同一条回复里讲：照着 DESIGN.md 的哪几节、读了哪些源码文件、用了底稿时底稿来自哪个地址；哪些是假数据、假操作，以及没打开网页工具、端口被占用、服务没跑起来等原因导致可能画得不准的部分；还没确认的问题。
- C2：原型里用到 DESIGN.md 没有的颜色、字号、间距、圆角、阴影或组件样式时 → 规程要求 Claude 在对话里逐个列出并问用户，用户同意写进 DESIGN.md，不同意就改用 DESIGN.md 里有的。
- C3：原型有 2 个及以上方案时 → 规程要求 Claude 在对话里讲每个方案的取舍，并问用户选哪个方案；方案的填写项只有 `id`、`label`、`desc`。
- C4：DESIGN.md「颜色」一节写了几套颜色（如明亮、暗黑），原型就在 `themes` 里声明几套，项目样式按每套主题写出对应颜色；只写了一套时不声明主题；用户要求看某套主题时照用户要求加。
- C5：对比时 → 只比布局、文案、每种状态、每个交互操作后的结果；示例数据（如订单号、人名、金额、数量、日期）和真实界面不同不算不一致；外壳的左栏和框上方一行不参与对比。原型声明了多套主题时，每套主题都要对比。
- C6：规程开头的一句话说明（skill 的 `description`）里写的外壳组成和右上角作用与 C1～C5 一致：左栏切页面和状态，右上角按需切方案和页面主题，没有底部说明。

## 验收

- [ ] C1：规程全文搜不到 `note`、`fake`、`openQuestions`；能找到"打开原型时在对话里讲依据、假的部分、未确认问题"的规定。
- [ ] C2：规程写明规范外样式在对话里逐个列出问用户，以及同意、不同意两种处理。
- [ ] C3：规程写明多方案时在对话里讲取舍并问选哪个；方案填写项只有 `id`、`label`、`desc`。
- [ ] C4：规程写明主题套数按 DESIGN.md「颜色」一节决定、一套时不声明、用户要求时照加。
- [ ] C5：对比一节写明示例数据不同不算不一致、外壳的左栏和框上方一行不参与对比、多套主题逐套对比；搜不到「底部说明」「只在原型里成立」。
- [ ] C6：`description` 里写的是右上角按需切方案和页面主题，没有"明暗主题""底部放说明"这类说法。

## 验证路径

1. 读 `/prototype` 规程 → 没有三个旧填写项，说明、假的部分、未确认问题都规定在对话里讲。
2. 在一个 DESIGN.md 写了明暗两套颜色的项目里运行 `/prototype` → 原型右上角有两套主题，Claude 的回复里讲了依据和假的部分。
3. 对一个只有示例数据不同的真实界面运行 `--compare` → 结果是「一致」。
