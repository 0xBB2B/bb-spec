# 右上角切换方案和页面主题

外壳是所有原型共用的 HTML 外框；"框"是外壳中间显示正式页面的区域。"方案"是同一份原型里并列给用户对比的几种设计，每个方案有短名（如「方案 A」）和一句特点（如「表格」）。"页面主题"是被设计页面自己的几套配色，在原型填写区里用 `themes` 声明，每套有 `id` 和显示名 `label`（如 `{ id: 'dark', label: '☾ 暗黑' }`）。

## 用户故事

### P0：作为看原型的用户，我想要切换被设计页面的主题，以便确认每套配色下页面的样子

**用例（主路径：明暗两套）**
- 场景：一份订单原型声明了 `light`「☀ 明亮」、`dark`「☾ 暗黑」两套主题，项目样式里给两套主题写了不同的底色；用户正在看方案 B 的「订单列表 · 出错」。
- 操作：点右上角「☾ 暗黑」。
- 预期：框里订单页换成暗黑底色；外壳配色不变；框里还是方案 B 的「订单列表 · 出错」，左栏选中项不变；「☾ 暗黑」变成选中样式。

**用例（边界：没有声明主题）**
- 场景：一份原型没有写 `themes`，或者只写了 1 套。
- 操作：打开原型。
- 预期：右上角没有「主题」两个字，也没有任何主题按钮。

**用例（边界：4 套主题）**
- 场景：一份原型声明了「默认」「暗黑」「节日」「高对比」4 套主题。
- 操作：打开原型，在右上角「主题」后面的下拉菜单里选「节日」。
- 预期：打开时菜单显示「默认」，框里是默认主题；选「节日」后框里换成节日配色，方案、页面、状态都不变。

### P0：作为对比方案的用户，我想要方案多时收进下拉菜单，以便框上方一行不被按钮挤满

**用例（主路径）**
- 场景：一份原型有方案 A～D 共 4 个方案。
- 操作：打开原型，在右上角「方案」后面的下拉菜单里选「方案 C：紧凑列表」。
- 预期：打开时菜单显示「方案 A：表格」；选完后框里换成方案 C 的同一个页面和状态，左栏写着「当前：方案 C：紧凑列表」，当前主题不变。

**用例（边界：3 个方案）**
- 场景：一份原型有 3 个方案。
- 操作：打开原型。
- 预期：右上角是「方案」和 3 个平铺按钮，不是下拉菜单。

## 约束

**显示规则**
- C1：方案或页面主题各自按数量决定样子 → 1 个或没有：不显示这一组（不显示「方案」或「主题」两个字）；2～3 个：显示组名和平铺按钮；4 个及以上：显示组名和一个下拉菜单，菜单里按填写顺序列出全部项。
- C2：方案按钮和方案菜单里每一项的文字是「<短名>：<特点>」，如「方案 A：表格」；主题按钮和主题菜单里每一项的文字是这套主题的 `label`。
- C3：两组都显示时 → 框上方一行右侧从左到右是「方案」组、一条细分隔线颜色的竖线、「主题」组；只显示一组时没有竖线，这一组靠右。
- C4：平铺按钮中当前项是选中样式；下拉菜单收起时显示当前项的文字。
- C5：左栏的页面、状态切换始终是平铺按钮，页面或状态有 4 个及以上时也不变成下拉菜单。

**页面主题**
- C6：打开原型时 → 当前主题是 `themes` 里的第一套；系统外观、上次选过什么都不影响。
- C7：框里页面的根元素带着当前主题的 `id`（如 `<html data-theme="dark">`），项目样式和终端页面的 `terminalCss` 可以按它给不同主题写不同颜色；没有声明主题时根元素不带这个标记。
- C8：切换主题 → 框里页面按新主题重新显示；当前方案、页面、状态和左栏选中项不变；外壳配色不变。
- C9：切换方案、页面、状态，或点框里的 `data-go` 跳转 → 当前主题不变。
- C10：`themes` 里某一项缺 `id` 或 `label`，或两项 `id` 相同 → 框里显示「原型填写有误」和出错的是哪一项。

**方案**
- C11：在方案按钮或方案菜单里换方案 → 框里换成这个方案的同一个页面和状态，左栏选中项不变，左栏顶部「当前：<短名>：<特点>」跟着变。

## 验收

- [ ] C1：方案数分别为 1、3、4，主题数分别为 0、1、2、4 时，右上角每组的显示样子符合约定；4 个时菜单里的项和填写顺序一致。
- [ ] C2：方案项文字是「方案 A：表格」这种格式；主题项文字等于 `label`。
- [ ] C3：两组都显示时顺序是方案组、竖线、主题组；只有主题组时没有竖线。
- [ ] C4：平铺按钮当前项是选中样式；下拉菜单收起时显示当前项。
- [ ] C5：一个页面有 5 个状态、原型有 4 个页面时，左栏仍是平铺按钮。
- [ ] C6：声明「☾ 暗黑」「☀ 明亮」（暗黑排第一）时，在浅色系统下打开，当前主题是「☾ 暗黑」。
- [ ] C7：当前主题是 `dark` 时框里页面根元素带 `data-theme="dark"`；终端页面同样带；没有声明主题时不带。
- [ ] C8：在方案 B「订单列表 · 出错」切到「☾ 暗黑」后，框里内容按暗黑主题显示，方案、页面、状态、左栏选中项不变。
- [ ] C9：切到「☾ 暗黑」后再切方案、页面、状态、点 `data-go` 跳转，当前主题仍是「☾ 暗黑」。
- [ ] C10：主题缺 `label`、缺 `id`、`id` 重复三种情况，框里都显示「原型填写有误」和出错项。
- [ ] C11：4 个方案时在菜单里选方案 C，框里是方案 C 的同一页面和状态，左栏显示「当前：方案 C：紧凑列表」。

## 验证路径

1. 打开 3 个方案、明暗两套主题的原型 → 右上角是方案组、竖线、主题组，都是平铺按钮，当前主题是第一套。
2. 点第二套主题 → 框里配色变，外壳和其余选中项不变。
3. 打开 4 个方案、4 套主题的原型 → 两组都是下拉菜单；分别换方案和主题，框里跟着变、另一组不变。
4. 打开 1 个方案、没有主题的原型 → 右上角是空的。
