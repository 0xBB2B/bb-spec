# 外壳精简

外壳是所有原型共用的 HTML 外框，上线后不存在。"框"是外壳中间显示正式页面的区域。"填写区"是原型文件里 `PROTOTYPE-START` 到 `PROTOTYPE-END` 之间、写原型内容的那一段，其余部分是外壳，出原型时不改。

## 用户故事

### P0：作为看原型的用户，我想要框占满窗口高度，以便一屏看到更多页面内容

**用例（主路径）**
- 场景：一份原型只有 1 个方案，窗口高 900 像素。
- 操作：打开原型。
- 预期：框下面没有任何说明区，框的下边缘离窗口底部 6 像素；外壳里找不到「这个画面的说明」「只在原型里成立」「还没确认的问题」「这一块上线后不存在」这些字。

### P0：作为看原型的用户，我想要外壳始终是暗黑配色，以便不用再管外壳的明暗

**用例（主路径：浅色系统）**
- 场景：用户的电脑设成浅色外观。
- 操作：打开原型。
- 预期：外壳是石墨深灰底、灰蓝虚线、浅色字。

**用例（边界：系统外观变化）**
- 场景：原型开着，系统是深色。
- 操作：把系统改成浅色。
- 预期：外壳配色不变。

### P1：作为写原型的 Claude，我想要填写格式里没有用不上的填写项，以便只写外壳会显示的内容

**用例（主路径）**
- 场景：Claude 打开外壳模板准备写原型。
- 操作：读填写区里的说明。
- 预期：说明里没有 `note`、`fake`、`openQuestions` 这三个填写项，方案的填写项只有 `id`、`label`、`desc`。

**用例（边界：旧写法）**
- 场景：一份原型的填写区仍然写了 `note`、`fake`、`openQuestions` 和方案的 `note`，其中 `note` 写成了字符串而不是数组。
- 操作：打开原型。
- 预期：原型正常显示，框里是正式页面，没有「原型填写有误」提示；这些内容在外壳上哪里都不显示。

## 约束

- C1：外壳只有一套配色 → 底色 `#26282c`，细分隔线 `#3a3d43`，正文字 `#d4d4d4`，次要文字 `#8f949b`，虚线和强调色 `#8e9aa8`，网格线 `rgba(255,255,255,.03)`，选中按钮的填充 `#33363c`、字 `#e6e6e6`；系统是浅色还是深色、打开后系统外观怎么变，外壳配色都不变。
- C2：外壳由左栏、框上方一行、框三块组成，框下面没有说明区；框的下边缘离窗口底部 6 像素，窗口高度变化时框跟着变高变矮。
- C3：外壳上不出现「这个画面的说明」「只在原型里成立」「还没确认的问题」「这一块上线后不存在」这几段文字；左栏顶部的「设计说明 · 不属于页面」标签和「第 N 版 · 这一栏上线后不存在」保留。
- C4：填写区的说明里不出现 `note`、`fake`、`openQuestions` 三个填写项；方案的填写项是 `id`、`label`、`desc` 三项，方案缺 `desc` 且方案数 ≥ 2 时 → 框里显示「原型填写有误」和缺了哪个方案的 `desc`。
- C5：填写区仍写了 `note`、`fake`、`openQuestions` 或方案的 `note`（不论写成什么类型）→ 原型照常显示，这些内容不出现在外壳上，也不触发「原型填写有误」。
- C6：外壳模板自带的示例原型里没有 `note`、`fake`、`openQuestions` 和方案的 `note`。

## 验收

- [ ] C1：分别模拟浅色、深色系统外观打开原型，外壳各项颜色都等于约定值；打开后切换系统外观，外壳颜色不变。
- [ ] C2：外壳里没有说明区元素；窗口高 900 像素时框下边缘在第 894 像素处。
- [ ] C3：外壳模板里搜不到那四段文字；能搜到「设计说明 · 不属于页面」和「这一栏上线后不存在」。
- [ ] C4：填写区说明里搜不到 `note`、`fake`、`openQuestions`；2 个方案其中一个缺 `desc` 时框里显示「原型填写有误」和该方案的 `label`。
- [ ] C5：填写区写了字符串类型的 `note`、对象类型的 `fake`、方案 `note` 时，原型正常显示，框里不是错误提示。
- [ ] C6：外壳模板的示例原型里搜不到这四个填写项。

## 验证路径

1. 打开外壳模板自带的示例原型 → 外壳暗黑，框下面没有说明区。
2. 把系统外观从深色改成浅色 → 外壳不变。
3. 在填写区加一行 `note: '旧写法'` 后重新打开 → 原型正常显示，外壳上看不到「旧写法」。
